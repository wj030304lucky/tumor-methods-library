肿瘤研究方法学文献库 v1.0

使用方式
1. 双击 index.html 即可在浏览器打开。
2. 搜索、筛选、收藏、学习状态和个人笔记均可使用。
3. 学习记录保存在当前浏览器 localStorage；更换浏览器/电脑前请点“导出学习数据”。
4. 后续新增文献：编辑 data.js，在 window.PAPERS 数组中新增对象即可，无需修改页面结构。

建议维护字段
code / module / priority / title / authors / journal / year / methods / type / takeaway /
design / data / innovation / limitations / reuse / url

长期更新建议
- 每月或每两周筛查 Nature Medicine、Nature Cancer、JAMA Oncology、JCO、JNCI、Nature Reviews Clinical Oncology 等。
- 新增文献前先判断它属于：方法创新 / 顶刊应用 / 方法规范 / 领域综述。
- 避免为了数量堆文献，优先保留能明确回答“为什么用这个方法、怎样复用到课题”的文章。
